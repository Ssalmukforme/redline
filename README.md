# REDLINE

노을빛 골든 베이에서 경찰을 피해 생존 시간을 겨루는 로우폴리 3D 드라이빙 게임.

## 실행

```sh
npm install
npm run dev -- --port 5175
```

브라우저에서 http://localhost:5175 를 엽니다. Node.js 22.12 이상 권장.

## 조작

- W / ↑: 가속
- S / ↓: 브레이크, 후진
- A D / ← →: 좌우 조향
- Space: 드리프트
- Shift: 니트로 (자동 충전)
- Esc: 일시정지 / 계속
- 터치 화면: 하단 조작 버튼

## 구현 범위

- 실시간 3D 시작 화면, 조작 안내, 맵 안내, 로컬 기록표
- 골든 베이 맵 1개: 16개 블록, 25개 교차로, 공원, 해안 산책로
- 가속, 브레이크, 후진, 드리프트, 니트로, 충돌
- 도로 경로 탐색을 이용하는 경찰 추격
- 30초마다 수배 단계 상승, 경찰 증원, 속도 증가. 5단계 이후에도 속도 증가
- 경찰이 근접하면 체포 게이지 상승, 거리를 벌리면 감소
- 생존 시간 TOP 10을 localStorage에 저장하고, 결과 화면에서 이름을 입력해 Supabase 전체 랭킹(`ssalmuk_ranking`, 게임 `redline` · 보드 `golden-bay`)에 등록. 기록 창에서 전체 랭킹 / 내 기록 탭 전환
- 모바일 터치 조작, 일시정지, 탭 전환 시 자동 일시정지
- 브라우저에서 합성하는 엔진음과 사이렌 (우측 상단에서 활성화)

전체 랭킹은 로그인 없이 브라우저별 익명 ID와 플레이어별 최고 기록으로 순위를 매기며, 연결할 수 없어도 게임과 로컬 기록은 그대로 동작합니다. 랭킹 클라이언트는 `src/ranking.js`, 보드 등록은 `src/ranking-boards.js`·`supabase/ranking-boards.sql`(생존 시간 ms, 클수록 좋음, 최대 2시간)입니다. Google Fonts를 불러오지 못해도 대체 글꼴로 실행됩니다. 게임 지형, 자동차 및 소리는 외부 에셋 없이 생성합니다.
